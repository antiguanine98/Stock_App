# Stock_App v1.11

생약표준품 재고 엑셀을 연도별 최종 재고량 기준으로 소급 보정하고, 품목/카테고리 추이 차트·3D 시각화·Gemini AI 분석을 제공하는 데스크톱 앱입니다.

## v1.11 주요 변경

- 스플래시: 이중 테두리 + **반투명 유리창** 패널
- **3D/통합 시각화**: 총 변동량 × 잔존 예상 소진기간(로그) × 연평균 분양량 산점도 (`viewer.html` + QWebEngineView)

## v1.1 주요 변경

- 변경일자/재고량 키워드 기반 **동적 컬럼 탐색** (규격·단위·가격 등 추가 열 허용)
- 등록일자 제외, 잔고 → **재고** 표기
- 표준품구분 정제 + 카테고리 필터 차트
- 연도별 최종 재고 소급 보정 + 차트 hover 툴팁
- 생약표준품 분양/소진 예측 AI 리포트
- 3D/통합 시각화 탭, 스플래시, 제작자 표기

## 엑셀 양식

| 구분 | 컬럼 |
|------|------|
| 기본정보 | 순번, 표준품구분, 관리번호, 한글명, 영문명, 재고(잔고), 분양여부 등 |
| 변동기록 | 변경일자N, 재고량N (컬럼명 키워드로 동적 탐색) |

- 품목 식별자: **관리번호**, **한글명**
- 연도별 최종 재고량을 기준으로 증가 시 과거 연도를 소급 보정합니다.

## 실행

```bash
pip install -r requirements.txt
python main.py
```

Gemini API Key는 앱 상단 입력란에 입력 후 [저장]하면 `config.json`에 보관됩니다. (`config.json`은 Git에 포함되지 않습니다.)

## 실행 파일

```bash
python -m PyInstaller --noconfirm --clean main.spec
```

생성 위치: `dist/Stock_App_v1.11.exe`

## 탭 기능

1. **보정 데이터 표** — 행 더블클릭 시 해당 품목 차트로 이동
2. **재고 추이 차트** — 표준품구분/품목 선택, hover로 일자·수량 확인
3. **AI 분석 리포트** — 분양 속도·소진 예측·5년 고갈 경고
4. **3D/통합 시각화** — 총 변동량 × 잔존 예상 소진기간(년, 로그) × 연평균 분양량
