## 실행

```bash
pip install -r requirements.txt
python main.py
```

Gemini API Key는 앱 상단 입력란에 입력 후 [저장]하면 `config.json`에 보관됩니다. (`config.json`은 Git에 포함되지 않습니다.)

## 실행 파일

```bash
# Windows EXE는 Python 3.12 환경에서 빌드하세요 (3.14는 R6034 런타임 오류 가능)
py -3.12 -m venv .venv312
.\.venv312\Scripts\pip install -r requirements.txt pyinstaller
.\.venv312\Scripts\python -m PyInstaller --noconfirm --clean main.spec
```

생성 위치: `dist/Stock_App_v1.44.exe`

## 탭 기능

1. **보정 데이터 표** — 행 더블클릭 시 해당 품목 차트로 이동 (연도 YYYY)
2. **재고 추이 차트** — 표준품구분/품목 선택, hover로 연도·수량 확인
3. **AI 분석 리포트** — 초기 리포트 + 대화형 추가 질문 (소진구간·신뢰도·제조검토/모니터링)
4. **3D/통합 시각화** — AI 추이: 연평균 분양량 × 예상 소진기간(최대 50년) × 순감소량 + AI 연동 필터
