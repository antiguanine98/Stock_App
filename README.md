# Stock_App

재고 엑셀(테스트파일1.xlsx 양식)을 소급 보정한 뒤, 품목별 추이 차트와 Gemini AI 분석을 제공하는 데스크톱 앱입니다.

## 엑셀 양식

| 구분 | 컬럼 |
|------|------|
| 기본정보 | 순번, 표준품구분, 관리번호, 한글명, 영문명, 잔고, 등록일자, 분양여부 |
| 변동기록 | 변경일자1, 재고량1, 변경일자2, 재고량2, … (I열 이후 쌍) |

- 품목 식별자: **관리번호**, **한글명**
- 동일 변경일자에 여러 재고량이 있으면 **마지막 값**으로 소급 보정합니다.

## 실행

```bash
pip install -r requirements.txt
export GEMINI_API_KEY=your_key   # AI 분석 탭에서 사용
python main.py
```

샘플 파일이 있으면 자동으로 `sample/테스트파일1.xlsx`를 로드합니다.

## 탭 기능

1. **보정 데이터 표** — 소급 보정 결과를 표로 표시. 행 더블클릭 시 해당 관리번호의 차트 탭으로 이동
2. **재고 추이 차트** — 콤보박스에서 `관리번호(한글명)` 선택, X=변경일자(YYYY-MM-DD), Y=재고량
3. **AI 분석 리포트** — 최초 대비 최종 수량 변화가 있는 품목만 Gemini에 전달
