# Stock_App v1.33

생약표준품 재고 엑셀을 연도별 최종 재고량 기준으로 소급 보정하고, 품목/카테고리 추이 차트·3D 시각화·Gemini AI 분석을 제공하는 데스크톱 앱입니다.

## v1.33 주요 변경

- 상단 엑셀/공정서/API Key를 **접이식 패널**로 통합
- 토글 또는 재고 파일 로드 완료 시 접어 **하단 탭·챗봇 영역**을 확대

## v1.32 주요 변경

- 챗봇 후속 질문 시 **재고 통합 DataFrame·지표를 실시간 재검토(Query)** 후 답변 (초기 리포트만 참조하지 않음)
- 공정서 DB를 후속 질문 컨텍스트에 함께 반영
- 시작 로딩창·작업 중 진행 다이얼로그가 Windows에서 보이도록 수정

## v1.31 주요 변경

- 신뢰도 **A~D** 등급(수집 횟수·관측 간격), 증가 구간 제외 분양속도
- 분양 가속도(급가속/증가/안정/감소), 장기 저분양 선별
- 현 재고×가격 **분양금액 환산액**(전체·유형별·TOP20)
- 리포트 최상단 **1페이지 KPI 대시보드** + 자동 종합 의견 (전문가 제언 섹션 제외)
- **공정서 DB** 별도 업로드: 재고 파싱 제외, AI/챗봇 규격·기준 참조 전용

## v1.3 주요 변경

## 엑셀 양식

| 구분 | 컬럼 |
|------|------|
| 기본정보 | 순번, 표준품구분, 관리번호, 한글명, 영문명, 재고(잔고), 분양여부 등 |

## 실행

```bash
pip install -r requirements.txt
python main.py
```

Gemini API Key는 앱 상단 입력란에 입력 후 [저장]하면 `config.json`에 보관됩니다. (`config.json`은 Git에 포함되지 않습니다.)

## 실행 파일

```bash
# Windows EXE는 Python 3.12 환경에서 빌드하세요 (3.14는 R6034 런타임 오류 가능)
py -3.12 -m venv .venv312
.\.venv312\Scripts\pip install -r requirements.txt pyinstaller
.\.venv312\Scripts\python -m PyInstaller --noconfirm --clean main.spec
```

생성 위치: `dist/Stock_App_v1.33.exe`

## 탭 기능

1. **보정 데이터 표** — 행 더블클릭 시 해당 품목 차트로 이동 (연도 YYYY)
2. **재고 추이 차트** — 표준품구분/품목 선택, hover로 연도·수량 확인
3. **AI 분석 리포트** — 초기 리포트 + 대화형 추가 질문 (소진구간·신뢰도·제조검토/모니터링)
4. **3D/통합 시각화** — AI 추이: 연평균 분양량 × 예상 소진기간(최대 50년) × 순감소량 + AI 연동 필터
